## Card identity

### Rank

`final enum Likewinter\CardDeck\Card\Rank: string`

A card rank. Pure identity — no intrinsic ordering or value.

Different games order ranks differently (poker, blackjack, belote, skat,
pinochle all disagree). Use a Likewinter\CardDeck\RankOrder to compare
ranks or get their values within a specific game's rules.

**Cases**

- `Joker = 'joker'`
- `Two = '2'`
- `Three = '3'`
- `Four = '4'`
- `Five = '5'`
- `Six = '6'`
- `Seven = '7'`
- `Eight = '8'`
- `Nine = '9'`
- `Ten = '10'`
- `Jack = 'J'`
- `Queen = 'Q'`
- `King = 'K'`
- `Ace = 'A'`

**Methods**

- **`#[NoDiscard] static fromSymbol(string $symbol): Card\Rank`**

  Look up a rank by its display symbol ("A", "2"…"10", "J", "Q", "K", "🃏").
  - **Throws:** `\InvalidArgumentException` — If the symbol is not a known rank.
- **`static casesWithoutJoker(): array`**

  - **Returns:** `list<Rank>`
- **`getSymbol(): string`**

  Returns the display symbol for the card rank.

### Suit

`final enum Likewinter\CardDeck\Card\Suit: string`

A card suit. Pure identity — includes the Joker "suit" so jokers can
be represented as regular Cards.

Suits have no intrinsic ordering; SuitOrder supplies trump and
lead-suit rules for trick-taking games.

**Cases**

- `Joker = 'joker'`
- `Hearts = 'hearts'`
- `Diamonds = 'diamonds'`
- `Clubs = 'clubs'`
- `Spades = 'spades'`

**Methods**

- **`#[NoDiscard] static fromSymbol(string $symbol): Card\Suit`**

  Look up a suit by its display symbol ("♥", "♦", "♣", "♠", "🃏").
  - **Throws:** `\InvalidArgumentException` — If the symbol is not a known suit.
- **`static casesWithoutJoker(): array`**

  - **Returns:** `list<Suit>`
- **`getColor(): string`**

  The conventional color of the suit: red (hearts, diamonds) or black (clubs, spades, joker). Used by games with alternating-color rules, e.g. Solitaire tableau building.
- **`getSymbol(): string`**

  Returns the display symbol for the suit, e.g. "♠".

## Core primitives

### Card

`class Likewinter\CardDeck\Card implements PlayableCard`

A playing card: a rank paired with a suit. Immutable and identity-only.

Card has no ordering and no game-specific semantics — those live in
RankOrder (for rank comparison) and SuitOrder (for trump/lead-suit
comparison). Use CardInPlay if you need face-up/face-down state.

**Properties**

- `$suit` (`Card\Suit`, readonly) — The card's suit.
- `$rank` (`Card\Rank`, readonly) — The card's rank.

**Methods**

- **`__construct(Card\Suit $suit, Card\Rank $rank)`**

  - `$suit` — The card's suit.
  - `$rank` — The card's rank.
  - **Throws:** `\InvalidArgumentException` — If exactly one of suit/rank is Joker — jokers pair the Joker suit with the Joker rank.
- **`#[NoDiscard] static fromString(string $string): Card`**

  Parse a card from its string form, e.g. "A♠", "10♦", or "🃏🃏" for a joker.
  - **Throws:** `\InvalidArgumentException` — If the string is not a valid card.
- **`__toString(): string`**

  Renders the card as rank symbol + suit symbol, e.g. "A♠".
- **`equals(PlayableCard $other): bool`**

  Two Cards are equal when they have the same suit and rank.
- **`isJoker(): bool`**

  Whether this card is a joker.
- **`underlyingCard(): Card`**

  Returns this card itself — a Card is its own underlying card.

### CardInPlay

`final readonly class Likewinter\CardDeck\CardInPlay implements PlayableCard`

A card with a face-up or face-down orientation, for games with partial
information (Solitaire, War, any game where some cards are hidden).

Card itself is immutable and orientation-agnostic. CardInPlay wraps a
Card and carries a Face state. Flipping returns a new instance rather
than mutating, preserving immutability of the underlying card.

Games that don't need face-down state can use Card directly and ignore
this class entirely.

**Properties**

- `$card` (`Card`) — The wrapped card.
- `$face` (`Face`) — Orientation; defaults to face-up.

**Methods**

- **`__construct(Card $card, Face $face = Face::Up)`**

  - `$card` — The wrapped card.
  - `$face` — Orientation; defaults to face-up.
- **`static up(Card $card): CardInPlay`**

  Create a face-up card in play.
- **`static down(Card $card): CardInPlay`**

  Create a face-down card in play.
- **`#[NoDiscard] flip(): CardInPlay`**

  Returns a new instance with the opposite face. Does not mutate.
- **`#[NoDiscard] reveal(): CardInPlay`**

  Returns a new instance face-up. No-op if already up.
- **`#[NoDiscard] hide(): CardInPlay`**

  Returns a new instance face-down. No-op if already down.
- **`isFaceUp(): bool`**

  Whether the card is currently face-up.
- **`isFaceDown(): bool`**

  Whether the card is currently face-down.
- **`__toString(): string`**

  Renders "██" when face-down, otherwise the wrapped card's string form.
- **`underlyingCard(): Card`**

  Returns the wrapped card, regardless of face state.
- **`equals(PlayableCard $other): bool`**

  Equal when both the wrapped card and the face state match.

### DeckBuilder

`class Likewinter\CardDeck\DeckBuilder`

Fluent factory for building decks of arbitrary composition.

Most games use the standard 52-card deck, but many need variations:
  - Jokers added (Canasta, some poker variants)
  - Multiple decks shuffled together (Blackjack shoe: 6×52)
  - Short decks (Euchre: 9-A, Piquet: 7-A)
  - Custom rank ranges and suit subsets
  - Duplicated cards (Pinochle: two of each 9-A per suit)

Usage:
  DeckBuilder::standard52()->build();
  DeckBuilder::standard52()->withJokers(2)->build();
  DeckBuilder::standard52()->times(6)->build();                 // Blackjack shoe
  DeckBuilder::range(Rank::Nine, Rank::Ace)->build();          // Euchre
  DeckBuilder::pinochle()->build();
  (new DeckBuilder())->suits(Suit::Hearts, Suit::Spades)->range(Rank::Seven, Rank::Ace)->build();

**Methods**

- **`static standard52(): DeckBuilder`**

  Start with a standard 52-card deck (4 suits × 13 ranks, no jokers).
- **`static standard52WithJokers(int $jokers = 2): DeckBuilder`**

  Start with a standard deck plus N jokers.
- **`static euchre(): DeckBuilder`**

  Build a Euchre deck: 9, 10, J, Q, K, A in all four suits (24 cards).
- **`static pinochle(): DeckBuilder`**

  Build a Pinochle deck: two of each 9, J, Q, K, 10, A in all four suits (48 cards). Note: Pinochle rank ordering differs from poker (10 is high, not Ace) — that's a RankOrder concern, not a deck composition concern.
- **`static piquet(): DeckBuilder`**

  Build a Piquet deck: 7, 8, 9, 10, J, Q, K, A in all four suits (32 cards).
- **`static ranging(Card\Rank $low, Card\Rank $high): DeckBuilder`**

  Start with a rank range (inclusive) in all four standard suits. Use after specifying suits, or use standard52() then range() to override ranks.
- **`suits(Card\Suit ...$suits): DeckBuilder`**

  Replace the suits used to build the deck.
- **`allRanks(): DeckBuilder`**

  Use all 13 standard ranks (Two through Ace, no joker).
- **`ranks(Card\Rank ...$ranks): DeckBuilder`**

  Replace the ranks used to build the deck.
- **`range(Card\Rank $low, Card\Rank $high, ?RankOrder $rankOrder = null): DeckBuilder`**

  Set ranks to a consecutive range (inclusive), using the given ordering to determine what's between $low and $high. Defaults to poker ordering (2 < 3 < ... < A) when no order is supplied.
  - **Throws:** `\InvalidArgumentException` — If $high cannot be reached from $low in the given ordering.
- **`withJokers(int $count = 2): DeckBuilder`**

  Add N jokers to the deck.
  - **Throws:** `\InvalidArgumentException` — If $count is negative.
- **`times(int $copies): DeckBuilder`**

  Repeat the entire deck N times (for multi-deck shoes like Blackjack). Jokers are not multiplied — they're added after the multiplied base.
  - **Throws:** `\InvalidArgumentException` — If $copies < 1.
- **`addExtra(Card ...$cards): DeckBuilder`**

  Add specific extra cards beyond the standard composition. Useful for custom decks or promotions.
- **`#[NoDiscard] build(): Stack`**

  Build and return the deck as a Stack.
- **`#[NoDiscard] buildCards(): array`**

  Build and return the deck as a list of Card objects (no Stack wrapper).
  - **Returns:** `list<Card>`

### DrawMode

`final enum Likewinter\CardDeck\DrawMode`

How a Table moves cards from the deck into hands.

**Cases**

- `Sequential` — Each hand receives its full draw before the next hand does.
- `OneByOne` — Cards are dealt one at a time, rotating through the hands.
- `Random` — Cards are taken from random positions in the deck.

### Face

`final enum Likewinter\CardDeck\Face: string`

Face-up / face-down state for a card in play.

Most games keep cards face-up once played. Games with partial
information (Solitaire tableau, War's face-down cards, hand cards
hidden from opponents) use Face::Down until a card is revealed.

**Cases**

- `Up = 'up'`
- `Down = 'down'`

**Methods**

- **`isUp(): bool`**

  Whether the card is face-up.
- **`isDown(): bool`**

  Whether the card is face-down.

### PlayableCard

`interface Likewinter\CardDeck\PlayableCard extends Stringable`

Common interface for anything that can occupy a slot in a Stack.

Card is the base case. CardInPlay wraps a Card with face-up/face-down
state. Wildcard wraps a Card with an optional substitution. All three
can live in a Stack, and all three can be compared by their string
representation for equality checks.

**Methods**

- **`underlyingCard(): Card`**

  The underlying Card this playable card represents. For Card itself, this returns $this.
- **`equals(PlayableCard $other): bool`**

  Identity check: is this the same playable card as $other? Used by Stack for removal and membership checks.

  Each implementation defines identity differently: - Card: same suit and rank. - CardInPlay: same underlying card AND same face state  
  (a face-up A♠ is not equal to a face-down A♠).  
  - Wildcard: same wild card, regardless of assignment  
  (an assigned joker equals an unassigned joker).

  Equality is type-narrowing: a Card never equals a CardInPlay wrapping the same card, and vice versa.
- **`__toString(): string`**

  Display form, consistent with Card::fromString() parsing (rank symbol + suit symbol), except where implementations signal hidden state (e.g. CardInPlay renders "██" when face-down).

### PlayerRing

`final class Likewinter\CardDeck\PlayerRing`

Turn order for a game: a rotating pointer over a fixed list of players.

Most card games use clockwise turn order with an optional 'skip' or
'reverse' modifier. This primitive captures the common case and lets
games query 'whose turn is it?' and 'advance to the next player'.

Players are identified by integer index (0-based). Games map these to
their own player representation (names, Stack objects, etc.).

**Properties**

- `$numPlayers` (`int`, readonly) — Number of players (>= 2).
- `$startingPlayer` (`int`, readonly) — Index of the player who acts first.

**Methods**

- **`__construct(int $numPlayers, int $startingPlayer = 0)`**

  - `$numPlayers` — Number of players (>= 2).
  - `$startingPlayer` — Index of the player who acts first.
- **`current(): int`**

  Returns the index of the player whose turn it is.
- **`next(): int`**

  Advance to the next player and return their index.
- **`peekNext(): int`**

  Returns the index of the next player (without moving the pointer).
- **`reset(): void`**

  Reset to the starting player.
- **`setCurrent(int $player): void`**

  Set the current player to a specific index.
- **`advance(int $steps): int`**

  Advance N steps around the ring.

### RankOrder

`final readonly class Likewinter\CardDeck\RankOrder`

Game-specific rank ordering and values.

A Rank by itself has no ordering — it is just an identity. Different games
order ranks differently (poker: 2 < 3 < ... < A; blackjack: J/Q/K all
equal 10; belote: J > 9 > A > 10 > K > Q > 8 > 7). This class encapsulates
a game's rank ordering so generic entities stay game-agnostic.

The "value" of a rank is an integer used for comparison; it has no
intrinsic meaning beyond ordering within a given RankOrder.

Construct via the static factories or fromRanks():
  RankOrder::poker()
  RankOrder::blackjack()
  RankOrder::fromRanks(Rank::Nine, Rank::Jack, Rank::Queen, Rank::King, Rank::Ten, Rank::Ace)

**Methods**

- **`static fromRanks(Card\Rank ...$ordered): RankOrder`**

  Build a RankOrder from an ordered list of ranks (lowest first).

  Each rank gets a value equal to its position (1-based). Duplicate values are not supported — for games where multiple ranks share a value (e.g. blackjack face cards), use the dedicated factory.
- **`static poker(): RankOrder`**

  Standard poker ordering: 2 < 3 < ... < K < A, with Ace highest. Values match rank face values (Two=2, ..., Ace=14) because PokerHand's wheel detection depends on them.
- **`static pokerLowAce(): RankOrder`**

  Poker ordering where Ace is treated as 1 (for the wheel straight A-2-3-4-5). Used by PokerHand for straight detection.
- **`static blackjack(): RankOrder`**

  Blackjack hard values: 2-10 at face, J/Q/K = 10, Ace = 11. Soft/hand-total logic is the game's responsibility.

  Note: J/Q/K share the value 10, so this cannot use fromRanks() (which assigns unique positional values).
- **`value(Card\Rank $rank): int`**

  The comparison value of a rank in this ordering.
  - **Throws:** `\InvalidArgumentException` — If the rank is not part of this ordering.
- **`compare(Card\Rank $a, Card\Rank $b): int`**

  Returns -1, 0, or 1 if $a is lower, equal, or higher than $b.
  - **Throws:** `\InvalidArgumentException` — If either rank is not in this ordering.
- **`isHigher(Card\Rank $a, Card\Rank $b): bool`**

  Whether $a ranks above $b in this ordering.
  - **Throws:** `\InvalidArgumentException` — If either rank is not in this ordering.
- **`isHighest(Card\Rank $rank): bool`**

  Whether $rank is the highest rank of this ordering.
- **`next(Card\Rank $rank): ?Card\Rank`**

  Returns the next-higher rank in this ordering, or null if $rank is the highest.
- **`previous(Card\Rank $rank): ?Card\Rank`**

  Returns the next-lower rank in this ordering, or null if $rank is the lowest.

### Stack

`class Likewinter\CardDeck\Stack implements IteratorAggregate, Countable`

An ordered collection of playable cards with an optional capacity.

Orientation: the top of the stack is the FRONT of the internal list —
takeTop()/peek() operate there — while addCards() appends to the
bottom. peek* methods inspect without removing; take* methods remove
and return the taken cards as a NEW Stack; move* methods transfer
cards between stacks.

Moves are transactional: if the target rejects the cards (for example
because its capacity would be exceeded), the cards are returned to
the source stack and the exception propagates.

**Properties**

- `$capacity` (`?int`, readonly) — Maximum number of cards this stack may hold; null means unlimited.

**Methods**

- **`__construct(iterable $cards = [], ?int $capacity = null)`**

  - `$cards` — Any iterable of items; each must implement PlayableCard (validated at runtime).
  - `$capacity` — Maximum number of cards this stack may hold; null means unlimited.
  - **Throws:** `\InvalidArgumentException` — If capacity < 1, an item is not a PlayableCard, or the initial cards exceed capacity.
- **`#[NoDiscard] static fromString(string $string, ?int $capacity = null): Stack`**

  Parse a comma-separated card string (e.g. "A♠,K♥,10♦") into a stack.
  - **Throws:** `\InvalidArgumentException` — If any segment is not a valid card string.
- **`getIterator(): Iterator`**

  Iterates over the cards from top to bottom.
- **`count(): int`**

  Returns the number of cards currently in the stack.
- **`__toString(): string`**

  Renders the cards as a comma-separated string, e.g. "A♠,K♥".
- **`isFull(): bool`**

  Whether the stack has a capacity and it is fully occupied.
- **`isEmpty(): bool`**

  Whether the stack holds no cards.
- **`isSame(Stack $other): bool`**

  Stacks are the same if they have the same number of cards and the same cards in the same order.
- **`enoughCards(int $num): bool`**

  Whether the stack holds at least $num cards.
  - **Throws:** `\InvalidArgumentException` — If $num < 1.
- **`hasCards(PlayableCard ...$cards): bool`**

  Check if the stack contains at least one match for each given card (using equals()). A single stack card can satisfy multiple query cards — use hasExactCards() when duplicates must match distinct stack entries.
- **`hasExactCards(PlayableCard ...$cards): bool`**

  Check if the stack has exactly the given cards, so if there are two of the same card and the stack contains only one, it will return false.
- **`addCards(PlayableCard ...$cards): void`**

  Append cards to the bottom of the stack.
  - **Throws:** `\InvalidArgumentException` — If the cards would exceed capacity.
- **`removeCards(PlayableCard ...$cards): void`**

  Remove the given cards, matched via hasExactCards() (distinct stack entries per query card).
  - **Throws:** `\InvalidArgumentException` — If the stack does not contain exactly these cards.
- **`#[NoDiscard] peek(int $num = 1): Stack`**

  Return the top $num cards as a new Stack WITHOUT removing them.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`#[NoDiscard] peekBottom(int $num = 1): Stack`**

  Return the bottom $num cards as a new Stack WITHOUT removing them.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`#[NoDiscard] peekRandom(int $num = 1): Stack`**

  Return $num randomly chosen cards as a new Stack WITHOUT removing them.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`#[NoDiscard] takeCards(int $num = 1): Stack`**

  Remove and return the top $num cards as a new Stack.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`#[NoDiscard] takeTop(int $num = 1): Stack`**

  Alias of takeCards(): remove and return the top $num cards.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`#[NoDiscard] takeBottom(int $num = 1): Stack`**

  Remove and return the bottom $num cards as a new Stack.
  - **Throws:** `\InvalidArgumentException` — If the stack has fewer than $num cards.
- **`moveTo(Stack $target, int $num = 1): void`**

  Move the top $num cards to $target.

  Transactional: if $target rejects the cards (e.g. its capacity would be exceeded), they are returned to this stack and the exception propagates.
  - **Throws:** `\InvalidArgumentException` — If this stack has fewer than $num cards or the target rejects them.
- **`moveAllTo(Stack $target): void`**

  Move every card to $target. No-op if this stack is empty.
  - **Throws:** `\InvalidArgumentException` — If the target rejects the cards.
- **`moveCardsTo(Stack $target, PlayableCard ...$cards): void`**

  Move specific cards to $target, matched via hasExactCards().
  - **Throws:** `\InvalidArgumentException` — If the cards are not all present in this stack.
- **`sortByRank(RankOrder $rankOrder): void`**

  Sort the cards in ascending order by rank using the given RankOrder.
- **`getRanks(): array`**

  The ranks of all cards in the stack, in stack order.
  - **Returns:** `list<Rank>`
- **`hasRank(Card\Rank $rank): bool`**

  Whether at least one card in the stack has the given rank.
- **`getSuits(): array`**

  The suits of all cards in the stack, in stack order.
  - **Returns:** `list<Suit>`
- **`sort(callable $callback): void`**

  Sort the cards in place using a comparison callback, like usort().
- **`shuffle(): void`**

  Randomize the order of the cards in place.
- **`clear(): void`**

  Remove all cards from the stack.

### SuitOrder

`final readonly class Likewinter\CardDeck\SuitOrder`

Game-specific suit ordering and trump rules for trick-taking games.

Encapsulates the full question 'does card A beat card B in this trick?'
given a trump configuration, the suit that was led, and the rank
ordering. Games construct a SuitOrder with their trump rules and
rank ordering, then use beats() to resolve tricks.

**Properties**

- `$trumpSuit` (`?Card\Suit`) — The trump suit, or null for no trump.

**Methods**

- **`__construct(?Card\Suit $trumpSuit, RankOrder $rankOrder)`**

  - `$trumpSuit` — The trump suit, or null for no trump.
  - `$rankOrder` — Rank comparison rules used within suits.
  - **Throws:** `\InvalidArgumentException` — If $trumpSuit is the Joker suit.
- **`static noTrump(RankOrder $rankOrder): SuitOrder`**

  No trump suit — only lead suit and rank decide tricks.
- **`static suit(Card\Suit $suit, RankOrder $rankOrder): SuitOrder`**

  Trump configuration with the given suit as trump.
- **`isTrump(Card $card): bool`**

  Whether the card belongs to the trump suit. Always false in no-trump.
- **`beats(Card $a, Card $b, ?Card\Suit $leadSuit): bool`**

  Does $a beat $b in a trick where $leadSuit was the first card's suit?

  Rules (standard trick-taking):  
  1. Trump beats any non-trump.  
  2. Higher trump beats lower trump.  
  3. Within the same suit, higher rank beats lower rank.  
  4. A card not following the lead suit cannot win unless it's trump.  
  5. If neither card follows lead and neither is trump, neither beats  
  the other — returns false (the lead card remains winning by  
  default; the caller resolves ties by keeping the current winner).

### Table

`class Likewinter\CardDeck\Table`

The card table: owns the deck, named hands, and pile for a game session.

Table is the single orchestration point for card movement. Games register
named hands, draw cards into them, discard back to the pile, and reset
for a new round — all through this interface. The underlying Stacks are
private; games interact only through Table's behavioral methods.

Hands are keyed by string identifiers chosen by the game:
  $table->addHand('dealer', new Stack());
  $table->addHand('north', new Stack(capacity: 13));
  $table->draw('north', 5);

**Methods**

- **`__construct(Stack $deck, DrawMode $drawMode = DrawMode::Sequential, bool $shuffle = false)`**

  - `$deck` — The draw pile; the table owns it from here on.
  - `$drawMode` — How draw()/drawAll() move cards from the deck into hands.
  - `$shuffle` — Shuffle the deck immediately.
- **`addHand(string $name, Stack $hand): void`**

  Register a named hand.
  - **Throws:** `\InvalidArgumentException` — If a hand with this name already exists.
- **`removeHand(string $name): void`**

  Remove a named hand, moving its remaining cards to the pile.
- **`hand(string $name): Stack`**

  Returns the named hand.
  - **Throws:** `\InvalidArgumentException` — If no hand with this name exists.
- **`hasHand(string $name): bool`**

  Whether a hand with this name has been registered.
- **`handNames(): array`**

  Names of all registered hands, in registration order.
  - **Returns:** `list<string>`
- **`draw(string $name, int $num = 1): void`**

  Draw cards from the deck into a named hand. Respects the table's DrawMode (Random draws random cards).
  - **Throws:** `\InvalidArgumentException` — If the hand does not exist.
  - **Throws:** `\LogicException` — If the deck has fewer than $num cards.
- **`drawAll(int $num = 1): void`**

  Draw $num cards to every registered hand, respecting DrawMode.
  - **Throws:** `\LogicException` — If no hands are registered or the deck cannot cover the full deal.
- **`#[NoDiscard] drawUpTo(string $name, int $target): int`**

  Draw cards into a named hand until it reaches $target cards, or the deck runs out — whichever comes first.

  Returns the number of cards actually drawn.
  - **Throws:** `\InvalidArgumentException` — If the hand does not exist.
- **`discard(string $name, PlayableCard ...$cards): void`**

  Discard specific cards from a named hand to the pile. With no cards argument, discards the entire hand.
  - **Throws:** `\InvalidArgumentException` — If the hand does not exist or does not contain the given cards.
- **`collectToPile(PlayableCard ...$cards): void`**

  Collect cards from outside the table (e.g., played trick cards) into the pile so reset() can recover them.
- **`reset(): void`**

  Return all cards from hands and the pile to the deck.
- **`shuffle(): void`**

  Shuffle the deck. Does not affect hands or the pile.
- **`deckCount(): int`**

  Number of cards remaining in the deck.
- **`pileCount(): int`**

  Number of cards currently in the pile.
- **`#[NoDiscard] peekDeck(int $num = 1): Stack`**

  Peek at cards in the deck without removing them.
  - **Throws:** `\InvalidArgumentException` — If the deck has fewer than $num cards.
- **`#[NoDiscard] peekDeckBottom(int $num = 1): Stack`**

  Peek at cards from the bottom of the deck without removing them.
  - **Throws:** `\InvalidArgumentException` — If the deck has fewer than $num cards.

### Trick

`final class Likewinter\CardDeck\Trick`

A single trick in a trick-taking game: the cards played by each player
in one round of play, plus the rules to determine the winner.

A trick starts when the current player leads a card. Each subsequent
player plays in turn order (enforced internally via PlayerRing). When
all players have played, winner() returns the index of the player
whose card won the trick, determined by the SuitOrder.

Trump rules, lead-suit rules, and rank ordering are all carried by
the SuitOrder supplied at construction.

**Methods**

### Wildcard

`final readonly class Likewinter\CardDeck\Wildcard implements PlayableCard`

A wildcard (typically a joker) that can stand in for another card.

Card itself is immutable and cannot be reassigned to a different
rank/suit. Wildcard wraps a joker (or any card acting as wild) and
tracks which card it currently represents. Assignment returns a new
Wildcard instance, preserving immutability.

Games without wildcards (standard poker, bridge, etc.) can ignore this
class entirely. Games with wildcards (Canasta, joker poker, Crazy
Eights with wild 8s, Rummy variants) use Wildcard to track the
substitution without mutating the underlying Card.

**Properties**

- `$wild` (`Card`) — The wild card itself (typically a joker).
- `$assigned` (`?Card`) — The card it currently represents, if any.

**Methods**

- **`__construct(Card $wild, ?Card $assigned = null)`**

  - `$wild` — The wild card itself (typically a joker).
  - `$assigned` — The card it currently represents, if any.
- **`#[NoDiscard] assign(Card $card): Wildcard`**

  Returns a new Wildcard with the assigned substitution card.
- **`#[NoDiscard] unassign(): Wildcard`**

  Returns a new Wildcard with no assignment (un-assigns the wildcard).
- **`effective(): ?Card`**

  The card this wildcard currently represents, or null if unassigned.
- **`isAssigned(): bool`**

  Whether the wildcard currently represents a card.
- **`isUnassigned(): bool`**

  Whether the wildcard does not yet represent a card.
- **`__toString(): string`**

  Renders the assigned card if set, otherwise the wild card itself.
- **`underlyingCard(): Card`**

  The assigned card if set, otherwise the wild card itself.
- **`equals(PlayableCard $other): bool`**

  Two wildcards are equal when their wild cards match, regardless of assignment.
